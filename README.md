# نور — تطبيق مواقيت الصلاة والقبلة والمصحف والأدعية

تطبيق Android عربي RTL مبني بـ HTML/CSS/JavaScript داخل Capacitor، مع طبقة Android أصلية للأذان والتنبيهات والبوصلة وتحديد الموقع.

### صورة رأس الصفحة
تمت إضافة الصورة المطلوبة في أعلى الصفحة الأولى داخل `www/assets/images/noor-header.jpg`، وهي مضمّنة داخل المشروع وتعمل دون اتصال بالإنترنت.

## ما هو مضمّن
- واجهة عربية RTL بالألوان الكحلية والذهبية والكريمية ووضع ليلي.
- مواقيت فلكية محلية دون شبكة، مع المسجد الأقصى كافتراضي، ثم جنين والقدس الشريف ومدن فلسطين ومدن عربية رئيسية.
- طرق: الحساب المحلي الفلسطيني، رابطة العالم الإسلامي، الهيئة المصرية، أم القرى.
- اتجاه القبلة والمسافة من الإحداثيات المحلية، مع مستشعر TYPE_ROTATION_VECTOR عند توفره.
- المصحف كاملًا محليًا في `www/data/quran.json` (6236 آية / 114 سورة).
- أدعية محلية.
- إعدادات محلية في localStorage.
- جدولة تنبيهات Android عبر AlarmManager أصلي وإعادة الجدولة بعد الإقلاع وتغيير الوقت/المنطقة الزمنية.
- طلب إذن الإشعارات في Android 13+.
- طلب الموقع فقط عند اختيار المستخدم لتحديد موقعه.
- لا توجد Google Fonts أو CDN أو Quran API أو روابط صوت خارجية وقت التشغيل.

## مهم جدًا بشأن الأذان الصوتي
المشروع يحتوي ملفات `adhan_fajr.wav` و`adhan_normal.wav` لكنها **نغمة اختبار قصيرة** وليست تسجيل أذان. لم أضمّن تسجيل أذان لقارئ أو مؤذن من الإنترنت لأن حقوق إعادة التوزيع تختلف. لاستعمال أذان حقيقي، استبدل الملفات بملفات صوتية لديك حق توزيعها، مع إبقاء أسماء الملفات نفسها أو تعديل `AdhanService.java`.

## مصدر القرآن
النص الموجود في `quran.json` مأخوذ من ملف `qurantext-uthmani.def` ضمن حزمة TeX quran الموجودة في TeX Live، مع إبقاء النص دون تغيير في مضمونه. راجع `www/data/quran-attribution.txt` للحصول على بيان المصدر والترخيص، وراجع شروط Tanzil قبل إعادة التوزيع التجاري.

## المتطلبات
Capacitor 8 يتطلب Node.js 22 أو أحدث، وAndroid Studio حديثًا، وAndroid SDK. إصدار Capacitor Android 8 يستهدف SDK 36 ويستخدم minSdk 24. راجع الوثائق الرسمية قبل البناء إذا تغيرت إصدارات الأدوات.

## إنشاء/تحديث المشروع
من مجلد المشروع:

```bash
npm install
npx cap sync android
```

إذا كان مجلد `android` غير موجود في نسخة جديدة، استخدم:

```bash
npx cap add android
npx cap sync android
```

ثم:

```bash
npx cap open android
```

## بناء Debug APK

من Android Studio: افتح مجلد `android` ثم استخدم **Build > Generate App Bundles or APKs > Generate APKs**.

للبناء من سطر الأوامر، ثبّت Gradle 8.14.3 أو استخدم Gradle المثبت لديك ثم من مجلد `android`:

```bash
gradle assembleDebug
```

الناتج عادةً:
`android/app/build/outputs/apk/debug/app-debug.apk`

ملاحظة: ملف `gradle-wrapper.jar` الثنائي غير مُنشأ في هذه البيئة؛ لذلك لا أزعم أن `./gradlew` جاهز هنا. Android Studio يستطيع استخدام توزيعة Gradle المحلية/تنزيل التوزيعة المناسبة عند إعداد المشروع.

## بناء Release APK
أنشئ keystore خاصًا بك أولًا:

```bash
keytool -genkeypair -v -keystore noor-release.jks -keyalg RSA -keysize 2048 -validity 10000 -alias noor
```

بعد ذلك اضبط توقيع release في Android Studio أو في ملف Gradle الخاص بك، ثم:

```bash
gradle assembleRelease
```

الناتج عادةً:
`android/app/build/outputs/apk/release/app-release.apk`

للنشر في Google Play استخدم AAB:

```bash
gradle bundleRelease
```

## الأذان والتنبيهات
التطبيق يستخدم AlarmManager الأصلي. على Android 12+ توجد قيود على exact alarms. المشروع يستخدم `SCHEDULE_EXACT_ALARM` ويملك fallback إلى `setAndAllowWhileIdle()` إذا لم يكن الإذن الخاص بالمنبه الدقيق متاحًا. قد يتأخر fallback حسب وضع توفير الطاقة. هذا متوافق مع توجيهات Android التي تميز بين exact وinexact alarms.

## جدول رسمي محلي
يمكن استيراد JSON من المثال الموجود في `www/data/schedule-schema.example.json`. يجب أن يتضمن المصدر والسنة والتاريخ والمدينة والأوقات. لا يعلن التطبيق أن الحساب الفلكي مطابق رسميًا؛ العبارة المعروضة هي: «مواقيت محسوبة فلكيًا وقد تختلف دقائق عن الجداول المحلية المعتمدة».

## اختبارات JavaScript


الاختبارات تتحقق من:

- المسافة إلى مكة.
- ترتيب مواقيت الصلاة.
- التعامل مع المناطق الزمنية.
- وجود 114 سورة و6236 آية.

## اختبار Android اليدوي
1. تثبيت Debug APK على جهاز حقيقي.
2. اختبار فتح التطبيق دون إنترنت.
3. تغيير المسجد الأقصى/جنين/القدس الشريف.
4. مقارنة المواقيت مع جدول محلي معتمد، وليس افتراض التطابق.
5. تجربة نظام 12/24 ساعة.
6. تجربة الإقامات بعد إضافة واجهة الإقامة المطلوبة في إصدار لاحق.
7. إعطاء إذن الإشعارات واختبار تنبيه صلاة قريب.
8. رفض exact alarm واختبار fallback.
9. إعادة تشغيل الهاتف ثم التأكد من إعادة الجدولة.
10. تغيير المنطقة الزمنية ثم التأكد من إعادة الجدولة.
11. تشغيل البوصلة وتحريك الهاتف، ثم اختبار هاتف بلا مستشعر.
12. اختبار تحديد الموقع بعد منح/رفض الإذن.
13. البحث في المصحف دون شبكة.
14. تكبير وتصغير خط المصحف.
15. تشغيل/إيقاف ملف الصوت الاختباري.
16. اختبار الوضع الليلي.

لم يتم تنفيذ بناء Android فعلي داخل هذه البيئة، لأن أدوات Gradle/Android SDK وحزم Capacitor الأصلية غير مثبتة هنا. لذلك لا أصف المشروع بأنه APK مُختبر، ولا أضع رابط APK مزعومًا. الملفات المصدرية موجودة لتفتح في Android Studio وتُبنى هناك.
